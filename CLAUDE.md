# Chronos — notes for Claude (and for people)

Chronos is an interactive prototype for **global art history**: timeline, connections graph, movements, artists, artworks, historical events, quizzes, in English and Greek.
Stack: React 18, TypeScript, Vite 5, Tailwind 3.4, react-router (HashRouter), d3-force. Static site, no backend, no environment variables.
The owner writes in English, Greek and Greeklish: answer in Greek when they write Greek, otherwise in English.

## Commands

```bash
npm install
npm run dev                       # http://localhost:5173
npm run validate                  # data integrity (unique ids, every reference resolves)
npx tsc --noEmit -p .             # types
npx tsx scripts/check-i18n.ts     # untranslated UI strings
npm run build                     # tsc + vite build → dist/   (Cloudflare Pages: build `npm run build`, output `dist`)
```
Run **validate, tsc, check-i18n and build** before every push. Do not push a red build.

## Where things are

- `src/data/` — content only. `index.ts` merges everything and applies the Greek overlays (`src/data/el/*`). **`src/lib/repo.ts` is the only read API**; pages never import raw arrays.
  - *Full* records are hand-written (`traditions.ts`, `movements*.ts`, `artists.ts`, `artworks.ts`, `events.ts`, `events-more.ts` …); *index* records are generated from compact tables (`artist-index.ts`, `movement-index.ts`).
  - `extra-works.json` (+ `extra-works.ts`) — artworks added by scripts; `gallery-works.ts` — works supplied by the owner; `guernica.ts`, `key-works-restricted.ts` — in-copyright works shown **without** an image and with a link to the museum (`image.restricted`).
  - `event-links.ts` — links from historical events to works, artists and movements, each with a reason in English and Greek.
  - `artist-works.json`, `movement-works.json` — galleries and links per artist / movement (generated by scripts, see below). `art-quiz.ts` generates the picture quizzes from the artworks.
- `src/i18n/` — UI strings. **English text is the key**; Greek is in `src/i18n/el/*`. `t('…')` for every visible string. Greek content for records is an overlay by id in `src/data/el/*` (objects merge by key, arrays of objects by index, string arrays replace).
- `src/components/`, `src/pages/` — UI. `src/index.css` — design tokens. `tailwind.config.js` — colours and fonts.
- `scripts/` — data pipelines (Wikidata/Commons). They are slow on purpose and **not needed to build the site**. Run with `NODE_USE_ENV_PROXY=1 npx tsx scripts/<name>.ts`; they cache in `/tmp`.
  `find-works.ts` (artist galleries) · `find-links.ts` (WikiArt / official websites; hand-checked sites in `artist-sites.json`) · `find-movement-works.ts` · `find-extra-works.ts` and `add-key-works.ts` (artworks) · `find-portraits.ts` / `fetch-portraits.mjs`.
- `scripts/build-artifact.sh`, `scripts/build-site-zip.sh` — optional helpers that build a smaller single-file preview or a zip.

## Design rules (do not change without being asked)

- Palette: White `#ECE9E9`, Black `#1D2121`, Volt `#B9ED00`, Lean `#7182CB`, Heat `#FF6716`, Grey `#CECECE`. Entity-type fills are `--f-*` in `index.css`, with a text colour per type (`typeFill()` in `src/components/ui/typeStyles.ts`): white text on Tradition, Movement, Style, Place and Period, dark text on the rest. **Type is shown by colour and name, never by icon.**
- Fonts: Albert Sans (titles) and Aeonik Pro (body, and Greek titles; Albert Sans has no Greek). Page side padding steps up with the screen (`.page-x`: 120 / 200 / 240 px).
- Hero: black stage with a draggable 3D carousel (`HeroRing.tsx`). Filters sit in a left sidebar on every list page (`FilterLayout`).
- Accessibility: keep WCAG AA contrast, keyboard operation, `prefers-reduced-motion`. Check with axe if you change colours.

## Content and licence rules (important)

- Everything is **sample content** and is labelled so. Do not invent facts, dates, portraits or images. Unverified details are flagged "to be verified".
- Images are bundled in `src/assets/art/<artwork-id>.jpg` with credit and licence in `src/data/image-credits.json`. Only add images that are **public domain, CC0, CC BY or CC BY-SA** (checked on Wikimedia Commons). The scripts only accept works whose maker died in 1955 or earlier, or that were made before 1901.
- **Never add an image of a work that is still in copyright** (for example Picasso's *Guernica*). Keep the record, set `image.restricted` and link to the museum, as in `src/data/guernica.ts`.
- **Artworks without an image are not listed anywhere** (`hasImage` in `src/lib/repo.ts`), except those with `image.restricted`.
- A few images were supplied by the owner (Monet, Gauguin, Hopper, and four works flagged "In copyright" in `image-credits.json`). Their licence status must be confirmed by the owner before public use.
- Links: WikiArt links only where the page exists; official websites only for the artist's own, estate's or foundation's site.
- Aeonik Pro is a commercial font: the licence must cover web use.

## Adding things

- **An artwork**: add the record, the image, the credit, the Greek overlay, and links to its artist (`created_by`) and to any historical event (`event-links.ts`). Then run the four checks.
- **A historical event**: add it to `events-more.ts` with a "What happened" and a "Connection to art" section, add the Greek overlay in `src/data/el/events-more.ts`, and link works/artists/movements in `event-links.ts` with a reason in both languages. Only link where the connection is documented.
- **A UI string**: use `t('English text')` and add the Greek to the right file in `src/i18n/el/`.

## Deployment

Cloudflare Pages: Framework preset **None** (or Vite), build command **`npm run build`**, output directory **`dist`**, `NODE_VERSION=22` (`.node-version`). Hash routing means no redirect file is needed.
